# Casio-Z-1GR-Emulator

Live demo: https://dylan7474.github.io/Casio-Z-1GR-Emulator/

This model faithfully recreates the iconic mid-90s Japanese "Pokekon" (Pocket Computer) with its 16-bit architecture (Intel 80L188EB compatible), wide landscape chassis, dual-mode 192×32 pixel / 4-line × 32-character LCD, full QWERTY keyboard with numeric keypad, piezo beeper, and working interpreters for BASIC, C Language, CALC, and SYSTEM inspection.
