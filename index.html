CASIO Z-1GR Pocket Computer Reference

1. System Modes

  • MENU: Returns to system selector: [1] CALC, [2] BASIC, [3] C, [4] CASL, [5] SYSTEM.
  • CALC: Immediate scientific calculator mode with direct formula evaluation.
  • BASIC: Casio Pokekon BASIC interpreter with full 192×32 graphics engine.
  • C-MODE: The C interpreter modeled on the famous Casio 16-bit C system.
  • CASL: COMET/CASL machine assembler simulator mode.

2. Built-in Commands (BASIC & System)

Type these directly into BASIC mode and press RET:

RUN - Execute loaded program
LIST - Display program lines
NEW - Clear current program
CLS - Clear LCD screen

3. Graphics Primitives (192 × 32 Pixels)

  • PSET(x, y) - Turns pixel on (x: 0-191, y: 0-31)
  • PRESET(x, y) - Clears pixel
  • LINE(x1, y1)-(x2, y2) - Draws line vector
  • CIRCLE(x, y, r) - Draws circle with radius r
  • LOCATE col, row - Sets cursor position (col: 0-31, row: 0-3)
